# Паттерн Адаптер (Adapter Pattern)

## Описание

Паттерн Адаптер позволяет объектам с несовместимыми интерфейсами работать вместе. Он оборачивает существующий класс в
новый интерфейс, делая его совместимым с кодом клиента.

## Проблема

В нашем проекте у нас есть:

- **Computer** - компьютер, который может подключать только USB-устройства
- **Headphone** - наушники с разъемом Jack 3.5 мм
- **Usb** и **Jack3_5** - несовместимые интерфейсы

Компьютер ожидает USB-устройство, но наушники имеют Jack 3.5 разъем. Как их подключить?

## Решение

Мы создаем **UsbJackAdapter** - адаптер, который:

1. Реализует интерфейс **Usb** (который ожидает компьютер)
2. Содержит ссылку на устройство с **Jack3_5** разъемом
3. При вызове `connect()` делегирует выполнение наушникам
